# E-Dolphin IRUKA, site vitrine

Site une page pour IRUKA, le jet-ski électrique premium d'E-Dolphin.

- `index.html` : tout le code (HTML, Tailwind CSS via CDN, JavaScript, icônes Lucide).
- `assets/` : photos et visuels.

Ouvrir `index.html` dans un navigateur suffit. Pour le mettre en ligne gratuitement : GitHub Pages (Settings > Pages > branche `main`, dossier racine).

Avant la mise en ligne : brancher le formulaire « Liste prioritaire » sur un service de formulaires (Formspree, Brevo…), il ne transmet rien pour l'instant.
